Wireless Sensor Node

A stamp-sized ESP32-C3 board for environmental logging — designed around the battery, not the antenna.

Finished2025 — rev. as of 2026-04-02
PCBEmbeddedIoT
Source & BOM
Specification

At a glance

MCU
ESP32-C3FH4 (RISC-V, Wi-Fi 4 + BLE 5)
Sensors
SHT40 (temp/RH), BMP390 (pressure)
Power
18650 via MCP73831 (500 mA), LDO: TPS7A02 3.3 V
Sleep current
18 µA avg (deep sleep + sensor strapping)
Firmware
ESP-IDF C++, deep-sleep scheduler, OTA via GitHub releases
Enclosure
PETG snap-fit, wall mount with mounting plate
SENSOR-NODE · REV A

Design goal

“Room sensor” is a solved problem on paper and a teaching experience in practice. The goal was a node that runs a full winter on one 18650, posts to a plain HTTP endpoint, and wakes only when it must.

Design decisions

  • Battery first. Every subsystem check starts with current, not features. The wake budget is: connect, transmit, sleep — 1.6 s max active per 10-minute window.
  • Strapping pins are sacred. ESP32 module boot strapping is pre-committed on the board: no floating GPIO determines whether the device can start.
  • Firmware does (almost) nothing clever. Read sensors, publish JSON, sleep. Config lives on the web server; the node stays boring.

Build log highlights

  • First batch: hand-soldered 0402 passives under a stereo microscope. Yield 4/5; one tombstoned cap — the only real defect, fixed with a hot plate.
  • Antenna detuning from the enclosure PETG measured about 3 dB at the channel edge. Rev. B adds a taller keepout.
  • Deep-sleep current proved to be an exercise in what NOT to drive: the sensor’s pull-ups kept running from the LDO until I switched the sensor rail to a load switch.

What I learned

  • Test the sleep current before the features. It’s the number you can’t fix later.
  • Snap-fit enclosures with PETG creep more than expected near a radiator — keep 3 mm clearance to hot pixels.

Next steps

  • Rev. A built, shown running for 6 months
  • Dashboard endpoint hardened (rate limits + TLS)
  • Rev. B: antenna keepout
  • Second sensor type: door contact via reed switch
