Portable Bench Power Supply

A CV/CC lab supply with USB-PD input and honest current limits — small enough for the student desk.

BENCH-PSU · REV B

Why this build

Every lab bench list starts with a power supply. This one follows two rules: it must fit a desk drawer, and it must behave exactly like a proper supply under its thermal envelope — because a PSU that lies about its current limit teaches the wrong lesson.

Design decisions

  • Constant voltage first. The buck runs as a normal CV converter; the CC loop only pulls the feedback node over. Plain error-amp cross-switching — no trust in software loops for the actual regulation path.
  • USB-PD as input, not as feature. The output is fully galvanically isolated from the PD source via the power stage; the MCU reads the negotiated voltage and expects the hardware PD controller to keep its promise.
  • Everything measurable. Current sense is a shunt plus diff-amp, not an ADC guess.

Build log

The rev. B board stacks the input stage on the same layer as the power plane to keep the switching-node loop small. Bring-up order is written down before the first connection: 3.3 V riser → firmware blink → PD handshake test → buck unloaded → ramped load. Any step that fails, the log gets a figure and a fix.

What I learned so far

  • Layout beats topology on a partner gate pin — the number-one rev. A defect was a ground-return path, not component choice.
  • Software-loops make slow graphs. Trust the electronics for speed.

Next steps

  • Rev. B thermal run with constant 1 A load
  • CC-loop crossover measurement, tune compensation
  • LPC PD negotiation edge cases at 12 V
  • Print final enclosure; panel labels after the thermal data
